# roman-uddin.github.io

Personal website of Roman Uddin. All content lives in `index.html`; photos and covers are in `assets/img/`.

## Quick edits
- New op-ed: search for `panel-english` and paste a copy of the first `<li>...</li>` right after `<ul class="list">`, then change the link, title and date. The list shows six items before "Show all", so add `class="more" hidden` to the item that becomes seventh. Also update the "New in New Age" box near the top (search for `New in New Age`).
- Photo caption: search for the old caption and replace every match (it appears twice).
- New photo: upload it to `assets/img/`, copy the last `<button class="ph" ...>` line, change the file name, caption and `data-i` number, then add the same file and caption to the `photos` list near the end of the file.
- Global Up-To-Date cover: upload a real cover named `global-up-to-date-cover.jpg` and change `global-up-to-date-cover.svg` to `.jpg` in index.html.

Changes go live at https://roman-uddin.github.io within a few minutes of saving.
