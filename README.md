# roman-uddin.github.io

Personal website of Roman Uddin.

## Updating the site
- New op-ed: open `index.html`, find the "Op-eds in English" list, copy one `<li>...</li>` line, paste it at the top of its year, and change the title, date and link. Update the "Latest op-ed" block near the top too.
- New photo: upload the image into `assets/img/`, then copy one `<figure class="shot">` block in the Photos section and change the file name and caption. Also add it to the `photos` list near the end of the file so the enlarged view works.
- Changes appear at https://roman-uddin.github.io within a few minutes of saving.
